# Import.io icon source

The icon is derived from the public Import.io favicon at
https://www.import.io/assets/favicon.svg, retrieved 2026-11-07.
Only the SVG canvas was expanded to 128 × 128 with approximately 10% transparent
padding for Antigravity. The original paths and colors are unchanged.
